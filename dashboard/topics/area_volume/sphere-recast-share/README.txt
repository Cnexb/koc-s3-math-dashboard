Sphere Recasting Lab (QB11) — share package
============================================

Required files (keep together in one folder):
  1. sphere-recast-lab.html
  2. area-volume-recast-lab.js

How to open:
  - Double-click OPEN-SPHERE-RECAST.bat (Windows), or
  - Double-click sphere-recast-lab.html in Chrome / Edge / Firefox

Internet connection required for:
  - KaTeX math rendering (cdn.jsdelivr.net)
  - Google Fonts (fonts.googleapis.com)

No web server is needed — opening the HTML file directly works.
